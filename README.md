# BlueWave University Portal

A responsive university website built using HTML, CSS, JavaScript and Bootstrap 5.

## Features

- Responsive Design
- Bootstrap 5 UI
- Home Page
- About Page
- Courses Page
- Course Details Page
- Events Page
- Faculty Page
- Gallery Page
- Contact Page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
